# Roadmap

## v0.1.0 — Playable core (current)
- [x] Procedural asset pipeline (textures, music, SFX)
- [x] Core physics (jump feel, gravity, speed tiers, portals)
- [x] 17-level campaign with sequential unlock
- [x] Practice mode, checkpoints, ghost replays
- [x] Endless and Daily modes
- [x] Level editor with undo/redo and clipboard import/export
- [x] Settings, statistics, achievements, icon shop
- [x] 6 languages, 7 themes
- [x] Windows + Linux export presets

## v0.2.0 — GD-style forms
- [x] Ship / wave / UFO / ball forms with mode portals
- [x] Jump orbs (tap-bounce in any form)
- [x] New "Mode Circuit" level teaching all forms
- [x] Auto-retry (instant restart on death)
- [x] DXR2 replay format (held-state ghosts)
- [x] Critical collision fix: landing/wall/ceiling contact now correct

## v0.3.0 — Polish
- [ ] Level editor polish: multi-select, copy/paste, verify tool
- [ ] Controller vibration + screen-shake tuning
- [ ] Replay viewer (watch any saved run)
- [ ] More campaign levels (user-designed)
- [ ] Audio visualizer (beat-reactive scene shaders)

## v0.4.0 — Online
- [ ] Daily leaderboards (server-verified runs)
- [ ] Level sharing with codes
- [ ] Community translations in-app
- [ ] Steam or itch.io release pipeline

## Future ideas
- Co-op ghost racing
- Rhythm-scored runs (beat-perfect jumps give bonus)
- Level packs / weekly curated levels
