# Contributing

Thanks for helping DEX DASH!

## Ways to contribute

- **Levels** — build a level in the built-in editor and export it (clipboard).
  Paste it into a GitHub issue; good levels get added to the campaign.
- **Translations** — full string tables live in `scripts/autoload/Localization.gd`.
  Copy the `en` table and translate; missing keys fall back to English.
- **Bug reports** — include the version, platform, and steps to reproduce.
  Headless logs are a big help: run the game with `--verbose`.

## Code style

- GDScript with hard tabs, 4-space-ish visual depth (tab = one level).
- Explicit type annotations on all variables that are not literal-inferred.
  `var x := 1` is fine; `var x := some_variant()` is not (the project treats
  Variant inference warnings as errors).
- All gameplay constants live at the top of `Level.gd`.
- No external addons or assets — everything is generated by `tools/`.

## Verification

Every script must pass:

```bash
godot --headless --import --path .
godot --headless --check-only --script res://scripts/...   # each changed script
```

New scenes should run clean headless for a few seconds:

```bash
godot --headless --path . --quit-after 300 res://scenes/menu/LevelSelect.tscn
```

## Rebuilding assets

```bash
node tools/gen-all.js
```

Committing regenerated `.import` files and `.uid` files is required.
