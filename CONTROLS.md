# Controls

## In-game

| Action | Default bindings |
|---|---|
| Jump | Space, W, Up, Gamepad A |
| Pause / menu | Esc, Gamepad Start |
| Restart level | R |
| Auto-retry (next run) | R during death overlay |

Hold the jump key to jump higher. Release early for a short hop.

## Menus

| Action | Binding |
|---|---|
| Navigate | Mouse, or arrows / WASD |
| Accept | Enter, Space, or Gamepad A |
| Back / cancel | Esc, or Gamepad B |

## Editor

| Action | Binding |
|---|---|
| Place object | Left mouse button (drag to paint) |
| Erase | Eraser tool, or right mouse button over an object |
| Pan | Middle mouse button drag, or WASD / arrow keys |
| Zoom | Mouse wheel |
| Undo / redo | Ctrl+Z / Ctrl+Y |

## Rebinding

Settings -> Controls lets you add bindings to any action. Click a row and press
the key, gamepad button or mouse button you want to add. "Reset controls"
restores the defaults.
