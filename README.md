# DEX DASH

An original rhythm platformer built with **Godot 4.7** (GL Compatibility renderer).
Tap on the beat, thread the spikes, flip gravity through portals, and chase your
ghost through 17 hand-tuned campaign levels — or test your nerve in Endless,
Daily, and custom levels made in the built-in editor.

Everything in the game is original and generated by this repository: art atlases,
music, and sound effects are produced by the `tools/` scripts — no external
assets, no third-party art or audio.

## Features

- **17-level campaign** — Tutorial through Extreme plus the boss level *THE WARDEN*
- **Rhythm-driven gameplay** — 10 original synth tracks with beat-synced visuals
- **Portal system** — gravity, speed, size, dash, rotation, spin, teleport pairs
- **Practice mode** — checkpoints and infinite retries
- **Ghost replays** — race your best recorded run
- **Endless mode** — procedurally generated circuits with rising difficulty
- **Daily Challenge** — the same generated level for everyone, every day
- **Level Editor** — paint cells, undo/redo, playtest, export/import via clipboard
- **26 achievements**, icon shop (8 colors, 5 trails), lifetime statistics
- **6 languages** — English, Español, Deutsch, Français, Português, 日本語
- **7 color themes**, full settings (video, audio, controls, accessibility)
- **Windows & Linux** exports

## Playing

Download a release for your platform, or run from source:

```bash
# requires Godot 4.7.1 (Standard or Mono)
godot --path .
```

## Building from source

1. Generate assets (requires Node.js): `node tools/gen-all.js`
2. Open the project in Godot 4.7.1 and press Play.
3. To export: use the provided presets (`Windows Desktop`, `Linux/X11`), see [BUILD.md](BUILD.md).

## Project layout

```
scripts/autoload/   game systems (save, settings, audio, achievements, ...)
scripts/gameplay/   level simulation, rendering, replay, boss AI
scripts/menu/       all menu screens
scripts/editor/     the level editor
scenes/             scene files for boot, menus, editor and gameplay
assets/             generated textures, audio, fonts (see tools/)
tools/              asset generation pipeline (Node.js)
```
